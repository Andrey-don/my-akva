2.1. Устранение критических ошибок PHP

  • Обеспечить совместимость сайта с PHP 8.2/8.3
  • Устранить ошибку 404 на главной странице
  • Исправить устаревший код в файлах темы

2.2. Очистка и оптимизация плагинов

  • Удалить неработающие, устаревшие и небезопасные плагины
  • Привести список плагинов в актуальное состояние

2.3. Исправление совместимости JavaScript

  • Устранить конфликт библиотеки webflow.js с новой версией jQuery

2.4. Настройка отправки почты с сайта

  • Настроить SMTP для отправки писем через контактные формы
  • Настроить Contact Form 7

2.5. Настройка DNS и корпоративной почты

  • Настроить MX, SPF, DKIM, DMARC записи домена
  • Обеспечить доставку входящей почты на ящики сотрудников

2.6. Установка и настройка SSL

  • Подключить HTTPS, настроить редирект с HTTP на HTTPS
  • Устранить ошибки смешанного контента

2.7. Настройка безопасности

  • Установить и настроить плагин безопасности
  • Закрыть доступ к служебным файлам

2.8. Настройка SEO

  • Настроить плагин Yoast SEO для типов записей сайта

#ЗаписьЗначениеНазначение

2SPF (TXT @)v=spf1 include:_spf.yandex.net include:spaceweb.ru ~allАвторизация серверов отправки
3DMARC (TXT _dmarc)v=DMARC1; p=none; rua=mailto:info@2akva.ruПолитика проверки почты
4DKIM (TXT sweb._domainkey)Ключ SpacewebЦифровая подпись исходящих писем
Инцидент (14–16 марта 2026): В результате настройки SMTP MX-запись была ошибочно изменена на сервер Spaceweb, что привело к прекращению доставки входящей почты всем сотрудникам на 2 дня. 16 марта 2026 г. MX-запись восстановлена на Яндекс 360, доставка почты возобновлена.

Результат: Входящая почта на ящики @2akva.ru работает, письма с сайта не попадают в спам.
