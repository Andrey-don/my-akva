Техническое задание на выполнение работ

1 Наименование работ Техническое обслуживание и доработка сайта 2akva.ru на платформе WordPress
2 Место проведения работ Сайт 2akva.ru (хостинг Sweb.ru); локальная копия 2akva.local
3 Объёмы работ
  • Выявить причину ошибки 404 на главной странице и устранить её
  • Найти причину, по которой невозможно установить актуальную версию PHP 8.2/8.3, и обеспечить совместимость сайта с PHP 8.3
  • Проверить работу установленных плагинов, выявить и удалить неработающие
  • Исправить несовместимости JavaScript: устранить конфликт библиотеки webflow.js с jQuery 4.0, поставляемой в WordPress 6.9+
  • Настроить передачу данных из форм сайта на корпоративную почту и SMTP
  • Настроить DNS-записи домена: MX, SPF, DKIM, DMARC — для корректной работы корпоративной почты @2akva.ru
  • Подключить SSL-сертификат, настроить HTTPS и 301-редирект с HTTP
  • Настроить безопасность сайта: ограничить доступ к служебным файлам, установить и настроить плагин безопасности
  • Установить и настроить SEO-плагин (Yoast SEO) для всех типов записей сайта
  • Перевести видеоматериалы с YouTube в медиатеку сайта WordPress — для обеспечения независимости воспроизведения видео при блокировке YouTube на территории РФ
